# Автозапись демо-роликов (без ручных скринкастов)

## Запуск (один раз ставится, дальше просто `npm run record`)
```
cd stackbid-site/tools
npm install
npx playwright install chromium
npm run record
```

Через ~1-2 минуты в `tools/videos/` появятся готовые `.webm`-файлы — реальная запись живого stackbid.app в портретной ориентации 390x844, ровно то, что нужно исполнителю как исходник.

## Что уже записывается
- `sb-audit-tool-*.webm` — вкладка Audit: загрузка PDF сметы подрядчика → результат сверки с ценами
- `sb-estimate-and-share-*.webm` — смета на террасу → кнопка Copy summary
- `sb-roi-callout-*.webm` — выбор "Garage door" → блок ROI

## Как добавить сценарий для новой фичи (на будущее)
В `record-demo.js` — одна новая `async function scenarioX(page) {...}` с реальными кликами/вводом на живом сайте, плюс одна строка `await withRecording('имя', scenarioX);` в самом низу. Видео пишется автоматически, руками ничего щёлкать не нужно ни разу.
